Games folder

The folder Gamehub scans — your qBittorrent completed-downloads folder. It is treated as read-only: files are never renamed, moved, or modified, so torrents keep seeding.

With Docker, mount your NAS folder in docker-compose.yml (e.g. /mnt/nas/games:/games:ro) and point this at the mount — usually /games.

Fixed by the container

Server port (PORT, default 8686) and the config/database folder (DATA_DIR) are bootstrap values set via environment — everything else lives here in Settings.

Searches the Steam catalog and uses official portrait artwork, descriptions and release dates — works out of the box with no registration. Covers most PC games; add IGDB or RAWG below for console titles and non-Steam releases.
