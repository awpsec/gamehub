Games folder

checking…

The folder Gamehub scans — your qBittorrent completed-downloads folder. By default it is treated as read-only: files are never renamed, moved, or modified, so torrents keep seeding. (Opt into organizing it below.)

With Docker, mount your NAS folder in docker-compose.yml (e.g. /mnt/nas/games:/games:ro) and point this at the mount — usually /games.

Organize this library

off

Off by default — leave it off for a seeding folder. When on, Gamehub tidies the games folder arr-style: it renames each identified game folder to Title (Year), files update packages under updates/<game>/, and flags junk / duplicate copies for you to remove. It never deletes anything, and only ever touches folders inside this library.

If your original torrent packages seed from a separate folder, point this at it. It is left completely untouched. Organization refuses to run if this overlaps the library above — a safety guard so seeding files are never renamed.

Steam

built-in · no key needed

Searches the Steam catalog and uses official portrait artwork, descriptions and release dates — works out of the box with no registration. Covers most PC games; add IGDB or RAWG below for console titles and non-Steam releases.

RAWG

not configured

Free API key at rawg.io/apidocs. Large database, easiest to set up.

IGDB

not configured

Uses Twitch app credentials — create one at dev.twitch.tv/console/apps. Best cover art and summaries.

API key

When set, every API and download request must send it (X-Api-Key header). The desktop client has a field for it in its Settings; this web UI will prompt once.

Database backup

Your matches, cover overrides, categories, and playtime live in the database — the library folder itself is never modified. Gamehub keeps automatic rotated snapshots on the server; you can download one anytime. To restore, drop the file into the server's data folder as restore.db and restart.
