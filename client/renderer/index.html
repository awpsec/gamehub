Gamehub

Connect to a server

How it works

  • The server scans its games folder read-only — nothing is renamed or moved, so torrents keep seeding.
  • You browse it like a storefront and download over your network.
  • Games unpack & install into a games folder on this PC.
Gamehub

Use without a server

How it works

  • Store — your torrent / completed-downloads folder. Scanned as your storefront and only ever read, so seeding is never touched.
  • Library — installing copies a game out of the Store and unpacks it here. Play, updates and DLC all happen in the Library.
  • Optional: Gamehub can keep the Library tidy — “Title (Year)” folders. The Store is never renamed.
